# Photo drop

Drop real player photos here (including ones you've cleaned up with an image model) and run `./update.sh`.

- Name the file after the player: `Robert Ursery.jpg` or `robert-ursery-1.jpg` (the id in the app's URL, e.g. #/player/robert-ursery-1).
- Any image type works (jpg, png, webp, heic). It's resized to 900px and copied into `site/assets/players/`.
- A dropped photo beats every other source on that player's card.
- Optional credit: add a line to `credits.txt` like `robert-ursery-1 | Original: UConn Athletics archive | Restored by Jason`.
